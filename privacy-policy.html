DarkPattern Defuser Privacy Policy

Privacy Policy

Effective Date: October 25, 2026
Developer: Coder-0X

1. Zero Telemetry & Local Execution

DarkPattern Defuser operates with 100% client-side privacy. The extension does not record, transmit, monetize, or harvest user data. All dark pattern detection and element neutralization occurs strictly within your browser's local memory.

2. Permissions and Scopes

Permission Technical Purpose
storage Stores protection settings, defused dark pattern counts, and saved monetary amounts exclusively inside local browser storage (chrome.storage.local).
alarms Executes periodic lightweight maintenance and cache cleanup within the background service worker.
*://*/* Inspects web pages across e-commerce storefronts to identify manipulative countdown timers, fake viewer counters, and pre-selected checkout add-ons.

3. Source Code & Verification

DarkPattern Defuser is open-source. You can inspect the source code on GitHub at https://github.com/Coder-0X/darkpattern-defuser.
